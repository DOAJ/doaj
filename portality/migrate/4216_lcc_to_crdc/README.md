# Migration from LCC to CRDC

    python portality/upgrade.py -u portality/migrate/4216_lcc_to_crdc/migrate.json

# Code Mapping

Code mapping was generated by running

    python portality/scripts/list_subject_classifications.py

on an unmigrated index to get all the LCC codes currently in use.

Then we took the first N terms of the CRCD codes, and pasted them into the second column, so there's a one-to-one mapping between all the LCC codes and one CRDC code.  Excess CRDC codes are discarded.
